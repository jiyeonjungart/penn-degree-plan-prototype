# Penn Degree Plan — High-Fidelity Prototype

Static React prototype of [penndegreeplan.com](https://penndegreeplan.com/), matching Penn Labs' periwinkle UI, semester planner, PCR stats, requirements panel, and course dock.

**Live:** https://jiyeonjungart.github.io/penn-degree-plan-prototype/

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Deploy

```bash
npm run deploy
```

Publishes the Vite production build to the `gh-pages` branch (GitHub Pages).
